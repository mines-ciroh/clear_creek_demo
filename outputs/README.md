The two notebooks in this directory are used to help with the predicted outputs
generated by NextGen when run on the LSTMs.

The CAMELS_ROUTING notebook generates the weighted files and should be ran after
running NextGen and producing output files for each sub-basin. The notebook will
look at the predicted outputs and take the product of the prediction with the area
of the sub-basin, before summing them all and converting to streamflow. This is done
for the catchment files and nexus files separately.You will need to specify the
appropriate directory before running

The LSTM_EVALUATION notebook simply compares the weighted outputs with the observed streamflow
for each of the variables for each LSTM. It then produces plots to visualize the accuracy. You
can switch between which files you want to compare.
